Какое бывает железо

вычислительный блок

CPU (AMD, Intel, RISC-V)

Плюсы:

  • Дешево
  • Доступна вся RAM
  • Есть открытые архитектуры (RISC-V)

Минусы:

  • Медленно
  • Отнимает ресурсы у остальных задач

GPU (Nvidia, AMD, Intel)

Плюсы:

  • Быстро
  • Понятно
  • Есть много софта
  • Хороший параллелизм
  • Есть открытые архитектуры (AMD)

Минусы:

  • Дорого
  • Мало vRAM

NPU

Плюсы:

  • Наиболее эффективное железо

Минусы:

  • Небольшой модельный ряд доступен для покупки
  • Мало софта
  • Обычно небольшая мощность

Какое бывает железо

оперативная память

RAM

Плюсы:

  • Можно поставить хоть 4TB на сервер

Минусы:

  • Медленная (DDR4-DDR5)

Unified Memory

Плюсы:

  • Дешевый способ дать GPU много памяти

Минусы:

  • Медленная

vRAM

Плюсы:

  • Очень быстрая (DDR6-DDR7)

Минусы:

  • Дорогая
  • Мало (32GB / 80GB) на 1 чип

Мой опыт

железо

  • 512GB DDR4 RAM
  • 64-core AMD EPYC 7702p
  • 8TB pci 4.0 x16 NVMe SSD
  • 36TB datacenter grade HDD

Мой опыт

фирмварь

  • BIOS и BMC чипы - читаем прошивку SPI программатором -> сверяем со стоковой
  • BMC исторически очень плохо написаны -> OpenBMC если есть
  • Ethernet по USB, тк BMC висит на обычном ethernet тоже

Мой опыт

операционная система

Alpine Linux

Плюсы:

  • Малый вектор атаки тк минимальный набор сервсов
  • Musl вместо libc (security-hardened)

Минусы:

  • Шаг влево шаг вправо и не работает
  • Собирать софт из сорцов - обычное дело
  • Нет Nvidia драйвера

Debian-based Linux

Плюсы:

  • Все работает из коробки

Минусы:

  • БОльший вектор атаки тк больше лишних, ненужных или не понятных сервисов

OpenBSD

Плюсы:

  • Очень маленькое ядро (7M LoC vs 40M LoC у linux)
  • Security-focused

Минусы:

  • Не хватает оптимизаций
  • Нет драйверов Nvidia
  • Нет NUMA

Мой опыт

софт для инференса

llama.cpp

CPU инференс

Плюсы:

  • 0 dependency
  • Нет проблем использовать квантованные модели

Минусы:

  • Батчинг на CPU практически отсутствует

vLLM

Когда использовать:

Плюсы:

  • Можно батчить запросы

Минусы:

  • Нужны дорогие GPU

Ollama / LM Studio

Когда использовать:

Минусы:

  • Низкая производительность
  • Много лишнего

Безопасность

железо

  • На серверных платах есть Baseboard Management Controller (BMC)
  • Это ARM чип, который управляет всем
  • Стоковая прошивка легендарно небезопасна
  • OpenBMC - ваш выбор

Безопасность

сегментация сети

  • Закрываем фаерволом
  • Используем виртуальные линки внутри между контейнерами
  • Из VPN хорош Wireguard - легковесный около 4к строк в Linux Kernel

Безопасность

виртуализация и контейнеризация

  • Qemu для изоляции машин
  • Runc/docker для рабочих нагрузок
  • SEV-SNP - шифрованная память от гипервизора в AMD EPYC

Безопасность

чеклист-рекомендация

Фирмварь

  • Сбросить, зашить последний релиз
  • Брать OpenBMC-совеместимую плату

ОС

  • Опенсорсная (linux-подобная)
  • Небольшой вектор атаки

Софт

  • От проверенных вендоров

Изоляция

  • Разрешен только необходимый сетевой трафик
  • Полезная нагрузка разделена

Производительность

kv кеш, mmap, latency

KV cache

Плюсы:

  • Ускоряет работу

Минусы:

  • Требует оперативку

Memory map

Плюсы:

  • Можно не занимать оперативку весами модели

Минусы:

  • Медленнее если оперативная память это ботлнек
  • Подходит только для CPU инференса

Batch/очереди

Плюсы batch:

  • В среднем обрабатывается быстрее тк несколько за раз

Плюсы очереди:

  • Предсказуемый latency
  • Лучше работает на CPU

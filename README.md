## Trust boundary

`_trusted/` contains the authoritative specifications and security-critical code. Changes to it require human review by @enovikov11.

Everything outside `_trusted/` may be freely modified or regenerated by @enovikov11-ai-agent and must not be relied upon as a security boundary or source of truth.

Development is driven by human direction and agent self-feedback loops. Control is primarily retroactive, traceability is enforced by linear Git history, and security is enforced through compartmentalization, virtualization, and ACLs.
